## 🏗️ Proyectos Destacados e IaC

A pesar de mi perfil junior, aplico estándares avanzados de la industria en la gestión de infraestructura como código, demostrables en mis repositorios anclados:

* **Arquitectura GCP Modular:** Diseño de una infraestructura base en Google Cloud Platform completamente desacoplada utilizando el patrón "Blueprint/Component" de Terraform. El entorno incluye módulos externos para la gestión de APIs, redes (VPC), almacenamiento, Pub/Sub, IAM y monitorización.
* **Gestión de Estado y Entornos:** Separación estricta de entornos de desarrollo y producción utilizando backends remotos en Google Cloud Storage para asegurar el bloqueo y consistencia del estado (`.tfstate`).
* **Integración Continua:** Automatización de flujos de trabajo en GitHub Actions para validar formato (`terraform fmt`), planificar cambios (`terraform plan`) y aplicar despliegues condicionados por entorno.
